# 🔥 My Daily Strategy

My current target is:

### **2 LeetCode Problems Every Day**

I will try to maintain this even when motivation is low.

The objective is to build a habit where:

```text
Motivation → Optional
Consistency → Mandatory
```

Some days may be difficult. Some problems may take hours.

That's part of the journey.

If I cannot solve a problem immediately, I will:

1. Understand the problem carefully.
2. Try a brute-force approach.
3. Analyze why it works or fails.
4. Look for patterns.
5. Study better approaches when necessary.
6. Implement the optimized solution.
7. Understand the solution instead of blindly copying it.
8. Analyze Time & Space Complexity.
9. Record the problem in this repository.
10. Revisit difficult problems later.
